# 书屿 BookNook 前端项目

本目录为“书屿 BookNook｜校园智能借阅与阅读成长系统”的前端项目。

## 技术栈

- Vue3
- Vite
- Element Plus
- Axios
- ECharts

## 运行方式

```bash
npm install
npm run dev
```

访问地址：

```text
http://127.0.0.1:5173/login
```

前端通过 `vite.config.js` 中的 `/api` 代理访问后端 `http://127.0.0.1:8080`。

## 主要页面

- 登录页
- 仪表盘
- 图书馆藏
- 图书分类
- 读者管理
- 借阅办理
- 预约管理
- 馆藏日志
- 数据统计
- 阅读目标
- 猜你喜欢
